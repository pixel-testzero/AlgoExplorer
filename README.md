# AlgoGod или AlgoExplorer
[![.NET](https://img.shields.io/badge/.NET-8.0-blue)](https://dotnet.microsoft.com/)
[![C#](https://img.shields.io/badge/C%23-12-green)](https://learn.microsoft.com/ru-ru/dotnet/csharp/)
[![Tests](https://img.shields.io/badge/Tests-xUnit-brightgreen)](https://xunit.net/)

**AlgoExplorer** — это интерактивное консольное приложение на C#, предназначенное для изучения, визуализации и тестирования ключевых алгоритмов и структур данных. 

Проект решает задачу наглядной демонстрации работы алгоритмов, разделяя обучение на два режима: **Теория** (подробное объяснение идеи, псевдокод, анализ сложности и пошаговые примеры) и **Практика** (живая демонстрация работы алгоритма на конкретных данных).

---

## 🚀 Функциональность

- **Красивый консольный UI**: ASCII-арт баннер, цветовое кодирование и интуитивное меню.
- **Двойной режим работы**: Каждый раздел содержит подробную теоретическую справку и интерактивную демонстрацию.
- **5 ключевых тем курса**: Сортировки, Бинарное дерево поиска (BST), Графы, Динамическое программирование, Техника двух указателей.
- **Полное покрытие тестами**: Unit-тесты (xUnit) проверяют как основные сценарии, так и граничные случаи.

##  Использованные алгоритмы и структуры данных

| Тема | Реализация | Временная сложность | Пространственная сложность | Почему выбран этот подход |
| :--- | :--- | :--- | :--- | :--- |
| **Сортировки** | Merge Sort, Quick Sort | O(n log n) | O(n) / O(log n) | Демонстрация парадигмы «Разделяй и властвуй». Сравнение стабильного (Merge) и экономного по памяти (Quick) подходов. |
| **Деревья** | Бинарное дерево поиска (BST) | O(log n) в среднем, O(n) в худшем | O(n) | Позволяет динамически добавлять/удалять элементы с сохранением упорядоченности, в отличие от статического массива. |
| **Графы** | BFS, DFS, Алгоритм Дейкстры | O(V + E) / O((V+E) log V) | O(V) | Фундаментальные алгоритмы обхода и поиска кратчайшего пути во взвешенных графах. |
| **ДП** | Задача о рюкзаке 0/1 | O(n × W) | O(n × W) | Единственный способ гарантированно найти глобальный оптимум при неделимости предметов. |
| **Два указателя** | Поиск пары с заданной суммой | O(n) | O(1) | Оптимальный по памяти способ поиска в отсортированном массиве без использования дополнительных структур. |

## 🏛 Архитектурное обоснование решений

### 1. Представление графа: Список смежности vs Матрица смежности
**Выбор:** Список смежности (`Dictionary<int, List<(int To, int Weight)>>`).
**Обоснование:** 
- **Память:** В реальных задачах (дорожные сети, социальные графы) графы обычно *разреженные* (E ≪ V²). Список смежности требует O(V + E) памяти, тогда как матрица всегда требует O(V²). Для графа с 10 000 вершин и 20 000 рёбер матрица займёт 100 000 000 ячеек, а список — лишь около 30 000 записей.
- **Скорость обхода:** Алгоритмы BFS, DFS и Дейкстры постоянно перебирают соседей текущей вершины. В списке смежности это делается за O(deg(V)), а в матрице всегда за O(V), что неэффективно.
- **Гибкость:** Добавление новой вершины в `Dictionary` происходит за амортизированное O(1), тогда как матрица потребовала бы пересоздания всей двумерной структуры.

### 2. Задача о рюкзаке: Динамическое программирование vs Жадный алгоритм
**Выбор:** Динамическое программирование (Bottom-Up).
**Обоснование:** Жадный алгоритм (выбор предметов в порядке убывания удельной ценности `value/weight`) **не гарантирует** нахождения оптимального решения для задачи 0/1 (где предмет нельзя делить). 
*Контрпример:* Вместимость W=5. Предметы: A(вес=3, цена=4, ratio=1.33), B(вес=2, цена=3, ratio=1.5), C(вес=2, цена=3, ratio=1.5). 
Жадный алгоритм выберет B и C (общая цена = 6, вес = 4). Однако если бы существовал предмет D(вес=5, цена=7, ratio=1.4), жадный алгоритм всё равно выбрал бы B+C=6, тогда как глобальный оптимум — это D=7. ДП гарантирует нахождение точного оптимума за счёт перебора всех комбинаций через таблицу состояний.

## 🔄 Рассмотренные и отклонённые альтернативы

| Задача | Альтернатива | Причина отклонения |
| :--- | :--- | :--- |
| **Сортировка** | Сортировка вставками (Insertion Sort) | Имеет квадратичную сложность O(n²), что неприемлемо для массивов среднего и большого размера. |
| **Поиск пары (Two Pointers)** | Использование `HashSet` | Хотя время остаётся O(n), требуется O(n) дополнительной памяти для хранения хэш-таблицы. Два указателя решают задачу строго за O(1) памяти. |
| **Кратчайший путь** | Алгоритм Беллмана-Форда | Имеет сложность O(V·E), что значительно медленнее Дейкстры O((V+E) log V). Отрицательные веса рёбер в данной задаче не предусмотрены. |
| **Сбалансированное дерево** | AVL или Красно-чёрное дерево | Для базовой демонстрации принципов BST избыточно усложняет код. В документации и теории упомянут риск вырождения дерева и способы борьбы с ним. |

## 🧪 Тестирование

Проект включает набор модульных тестов на фреймворке **xUnit**, покрывающих:
1. **Основной сценарий**: Корректность работы алгоритма на стандартных валидных данных.
2. **Пустые входные данные**: Пустой массив, пустой граф, нулевая вместимость рюкзака.
3. **Минимальный размер**: Массив из 1 элемента, дерево из 1 узла.
4. **Заведомо недостижимый результат**: Поиск несуществующего элемента в BST, поиск суммы, которой нет в массиве, изолированные вершины в графе.
5. **Специфические случаи**: Отрицательные числа, дубликаты, уже отсортированные массивы.

Запуск тестов:
```bash
dotnet test tests/AlgoExplorer.Tests
```

Проект имеет чёткое разделение на модули по смысловым областям (SOLID, чистая архитектура):
```
AlgoExplorer/
├── src/AlgoExplorer/
│   ├── Algorithms/           # Реализации алгоритмов
│   │   ├── Sorting/          # Merge Sort, Quick Sort
│   │   ├── Graph/            # BFS, DFS, Dijkstra
│   │   ├── DP/               # Задача о рюкзаке
│   │   └── TwoPointers/      # Поиск пары с суммой
│   ├── DataStructures/       # Структуры данных
│   │   └── BST/              # Бинарное дерево поиска
│   ├── Demos/                # Практические демонстрации
│   ├── Theory/               # Теоретические материалы
│   ├── UI/                   # Пользовательский интерфейс
│   └── Program.cs            # Точка входа
├── tests/AlgoExplorer.Tests/ # Модульные тесты (xUnit)
├── AlgoExplorer.sln          # Файл решения
├── README.md                 # Документация
├── .gitignore                # Игнорируемые файлы
└── LICENSE                   # MIT лицензия

`Algorithms/Sorting/`     # Реализации Merge Sort и Quick Sort 
`Algorithms/Graph/`       # Алгоритмы BFS, DFS и Дейкстры 
`Algorithms/DP/`          # Динамическое программирование (рюкзак 0/1) 
`Algorithms/TwoPointers/` # Техника двух указателей 
`DataStructures/BST/`     # Бинарное дерево поиска с визуализацией 
`Demos/`                  # Сценарии практической демонстрации работы алгоритмов 
`Theory/`                 # Подробные теоретические описания с псевдокодом 
`UI/`                     # Консольный интерфейс: баннер, меню, хелперы 
`tests/`                  # Unit-тесты на xUnit (37 тестов) 
```
## ▶️ Как запустить

### Требования
Установленный [.NET 8 SDK](https://dotnet.microsoft.com/download) или новее

### Запуск приложения
Запуск можете осуществлять через терминал bash или PowerShell

### Перейдите в корневую папку проекта
```bash
cd AlgoExplorer
```
### Соберите проект
```
dotnet build
```
### Запустите интерактивное приложение
```
dotnet run --project src/AlgoExplorer
```

### Запуск тестов

```bash
dotnet test tests/AlgoExplorer.Tests
```
